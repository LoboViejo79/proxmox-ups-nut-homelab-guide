# Manual público: Proxmox + Hikvision DS-UPS2000-R + NUT

Sitio estático HTML/CSS/JS, listo para GitHub Pages y sin dependencias externas.

## Abrir localmente

Abre `index.html` en un navegador moderno. El buscador, simulador, botones de copiar y checklist funcionan sin servidor web.

## Publicar en GitHub Pages

1. Sube el contenido de esta carpeta a un repositorio.
2. En GitHub: **Settings → Pages**.
3. Selecciona la rama y la carpeta raíz del repositorio.
4. Guarda y espera el despliegue.

## Privacidad

Esta edición fue anonimizada para publicación pública: no contiene el hostname real, IPs internas, contraseñas ni el inventario exacto de VM/LXC. Las capturas originales que exponían esos datos fueron excluidas.

## Seguridad

Los comandos de FSD y `poweroff` pueden apagar equipos reales. Sigue la progresión de pruebas del manual y usa primero el shutdown simulado.
